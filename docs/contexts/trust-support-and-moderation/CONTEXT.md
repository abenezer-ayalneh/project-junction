# Trust, Support, and Moderation — Context Glossary

**Status:** Specified — Not Executed — Not Verified  
**Glossary only:** canonical language; no requirements or implementation detail.

| Term                  | Meaning                                                             | Avoid                     |
| --------------------- | ------------------------------------------------------------------- | ------------------------- |
| Support Case          | in-app assistance record scoped to an actor/context                 | general chat thread       |
| Return Case           | goods aftercare record for affected line/quantity                   | product exchange          |
| Dispute               | formal evidence-based financial/fulfillment/service resolution case | any complaint             |
| Policy snapshot       | purchased version of applicable policy                              | current Vendor policy     |
| Review                | verified post-completion Customer feedback                          | unverified rating         |
| Moderation case       | content/listing/review/enforcement assessment                       | automatic legal judgement |
| Appeal                | review of a moderation/enforcement decision                         | retry button              |
| Restricted suspension | constrained Vendor state preserving needed records/open obligations | erased Vendor             |
| Private inquiry       | offering-scoped nonpublic question/message                          | public Q&A                |
