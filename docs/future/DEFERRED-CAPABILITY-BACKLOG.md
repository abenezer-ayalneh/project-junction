# Deferred Capability Backlog

**Status:** Deferred; not a release commitment.  
**Decision coverage:** `DEC-013`, `DEC-015`, `DEC-050`, `DEC-051`, `DEC-098`, `DEC-102`, `DEC-123`, `DEC-134`, `DEC-135`, `DEC-149`, `DEC-150`

| Capability                                          | Why deferred/excluded                                 | Re-entry condition                                       |
| --------------------------------------------------- | ----------------------------------------------------- | -------------------------------------------------------- |
| Native mobile applications                          | PWA delivers portfolio target first                   | proven PWA evidence and justified platform need          |
| AI assistance/personalization beyond rules          | avoid fake intelligence and privacy risk              | narrow user-approved job, safety review, evidence        |
| Two-way calendar sync                               | Junction calendar must remain authoritative first     | conflict policy and provider contract completed          |
| C2C, rentals, quote jobs, home service              | changes marketplace/operational/financial model       | new product/market/policy design                         |
| Group capacity, resource capacity, recurring series | staff-only one-person Booking is the defined contract | separate allocation model and concurrency proof          |
| Public Q&A, live video, public messaging expansion  | moderation/privacy cost                               | durable trust controls and evidence                      |
| Wallet, escrow, cash on delivery, tax engine        | financial/regulatory implications                     | legal/payment/tax validation and redesigned ledger       |
| Dispatch, carriers, GPS tracking                    | Junction is not a fleet operation                     | explicit logistics model, liability, and operations plan |
| Advanced variants/bundles/subscriptions             | maintain catalog/checkout correctness                 | distinct lifecycle/policy requirements                   |

Deferred means no implied roadmap date. Any revival starts with a new decision, requirements, policies, states, security assessment, and test/evidence plan.
