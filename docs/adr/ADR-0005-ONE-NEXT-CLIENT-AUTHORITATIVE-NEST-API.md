# ADR-0005: One Adaptive Next Client with Authoritative Nest APIs

**Status:** Accepted target architecture; not implemented  
**Decision:** `DEC-079`, `DEC-119`, `DEC-127`  
**Date:** 2026-08-27

The target has a responsive installable Next PWA and authoritative Nest APIs. This avoids duplicate native/client business logic while keeping API contracts reusable. Native applications remain deferred, and UI convenience never becomes the authority for commerce rules.
