# ADR-0012: Isolated Synthetic Public Demo

**Status:** Accepted  
**Decision:** `DEC-107`, `DEC-109`, `DEC-139`, `DEC-172`, `DEC-177`–`DEC-178`  
**Date:** 2026-08-27

The public demo allows no-signup persona switching only within a synthetic, quota-bound workspace that expires at 24 hours and is purged. This adds isolation/cleanup work but lets reviewers see all roles without exposing real users, Vendors, money, or credentials.
