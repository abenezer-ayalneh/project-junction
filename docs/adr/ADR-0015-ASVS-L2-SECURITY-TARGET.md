# ADR-0015: ASVS 5.0 Level 2 Security Target

**Status:** Accepted target; not assessed or certified  
**Decision:** `DEC-153`  
**Date:** 2026-08-27

Use applicable OWASP ASVS 5.0 Level 2 as the security verification target. This gives a concrete review language without overstating certification. Applicability, evidence, and exceptions must be documented per release.
