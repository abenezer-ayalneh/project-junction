# ADR-0013: Quarantined Versioned Media Pipeline

**Status:** Accepted target architecture; not implemented  
**Decision:** `DEC-047`, `DEC-088`, `DEC-175`, `DEC-176`  
**Date:** 2026-08-27

Untrusted media is uploaded to quarantine, validated/processed, and promoted only as versioned safe assets. This delays publication and introduces operations work, but protects marketplace presentation and makes caption/no-speech accessibility enforcement possible.
