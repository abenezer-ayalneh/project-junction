# ADR-0002: Portfolio-First with Evidence-Gated Claims

**Status:** Accepted  
**Decision:** `DEC-003`, `DEC-004`, `DEC-139`  
**Date:** 2026-08-27

Technical hiring teams are the primary audience. Public claims must be backed by test/recovery/provider evidence and qualify sandbox/synthetic behavior. This increases documentation and testing work, but avoids an impressive-looking yet untrustworthy demo.
