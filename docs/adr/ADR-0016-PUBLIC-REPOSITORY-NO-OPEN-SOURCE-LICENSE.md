# ADR-0016: Public Repository without an Open-Source License

**Status:** Accepted future release posture; no repository initialized  
**Decision:** `DEC-112`, `DEC-113`  
**Date:** 2026-08-27

The intended portfolio repository is public for review but does not grant an open-source license during the portfolio phase. Documentation must make copyright/reuse posture clear and may accept issues while declining external contributions. This preserves demonstrability while retaining reuse control.
