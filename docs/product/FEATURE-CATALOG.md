# Feature Catalog

**Status:** Specified — Not Executed — Not Verified  
**Decision coverage:** `DEC-016`–`DEC-065`, `DEC-098`–`DEC-105`, `DEC-130`–`DEC-150`, `DEC-157`–`DEC-189`

| Capability group      | Included future capability                                                                                            | Principal exclusions/boundaries                                        |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Storefront/catalog    | Vendor-owned listings, structured branding, variants, media, CSV, publication review, typed Product/Service discovery | no shared canonical catalog/page builder/digital goods                 |
| Inventory/fulfillment | Location stock ledger, strict holds, delivery zones, pickup/delivery, milestones/proof                                | no backorders, fleet/carrier/GPS                                       |
| Scheduling            | Staff qualification/calendar/availability, fixed-duration booking, named/any staff, iCal export, online meeting       | no shared resources/group seats/recurring series/two-way calendar sync |
| Unified commerce      | local Cart merge, quote/hold, one payment, Purchase split to Vendor Orders/Bookings, coupons/campaigns                | no non-atomic partial checkout or wallet/escrow                        |
| Finance               | Stripe sandbox model, immutable ledger, delayed earnings, payout batches, reconciliation                              | no real commercial settlement or ledger edits                          |
| Trust/aftercare       | policy snapshots, returns/refunds, disputes, Support Cases, private inquiries, verified reviews, moderation/appeals   | no product exchanges, public Q&A, unreviewed enforcement               |
| Engagement            | wishlists, saved searches/services, follows/updates, opt-in explainable recommendations, first-party analytics        | no behavioral surveillance, fake ML, general social network            |
| Demo                  | no-signup personas, synthetic providers/data, role switching, 24-hour expiry/purge                                    | no real user/Vendor/payload/provider access                            |

Short public videos are a Release 1 portfolio capability and require captions or an explicit no-speech declaration plus description. All listed capabilities need their phase acceptance proof before they can be claimed as implemented.
