**Document status:** accepted baseline

**Normative owner:** individual `SRC-CHAT-*` classification and chronological anchor

## Use and interpretation

This appendix is the durable, normalized extraction of each substantive Project Junction chat selection. Source number is chronological; direct sources map to the `DEC-*` records whose linked normative owners contain the authoritative rules. A later direct selection may revise an existing decision and therefore map to several `DEC-*` records. The sentence below is a normalized source statement, not a substitute for the original raw conversation wording. Superseded sources remain visible rather than silently folded into later scope.

The raw Codex conversation is application metadata rather than a versioned repository artifact. This appendix preserves its decision-bearing content in versioned form: source order, normalized statement, classification, and decision anchor. It intentionally does not upgrade assistant recommendations into User decisions.
